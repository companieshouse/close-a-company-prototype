Application signed

The person who started the application can now pay for and submit it

You must inform all interested parties

When the person who started the application has submitted it, you'll be able to download a copy by signing back in to the Apply to strike off and dissolve a company service (opens in new tab). As the sole director, you must then send a copy of this application to all interested parties within 7 days.

If the application is accepted, we'll also publish a copy on the Companies House public register (opens in new tab). This could take up to 2 working days from when it's submitted.

Read the full list of interested parties you must tell about the company dissolving (opens in new tab).

! Warning It is a criminal offence not to tell all interested parties that an application has been made to dissolve a company.

Delete this application

If you no longer want to dissolve the company, or if there is an error in the current application and you want to start a new one, you can delete this application. We’ll ask you to confirm you want to do this on the next page.
